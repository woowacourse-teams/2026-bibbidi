# 피드백 수집

서비스 전체 의견은 헤더의 계정 메뉴 → 의견 보내기에서 받는다. 계정 메뉴는 로그인 상태에서만 표시하며, 비로그인 상태에서는 로그인 링크만 표시한다. 데스크톱은 Dialog, 모바일은 BottomSheet로 입력하며, 닫으면 헤더 메뉴 버튼으로 포커스를 돌려준다. 별도 플로팅 피드백 버튼은 표시하지 않는다.

AI 대화에서는 내용이 있는 완료 답변이 3개 쌓이면 세 번째 답변 아래에 피드백 카드를 표시한다. 실패·수신 중 답변은 세지 않으며, 같은 질문의 재시도를 중복으로 세지 않는다. 카드를 무시해도 대화를 계속할 수 있다. 평가를 고르면 선택 의견 입력과 전송 버튼을 표시한다.

닫기 또는 전송 성공 시 계정 ID별 localStorage 키 `bibbidi:ai-chat-feedback:authenticated:{id}`에 다음 노출 가능 시각을 저장하여 7일간 다시 묻지 않는다. 이 제한은 현재 브라우저에만 적용된다. 저장소 접근이 막혀도 현재 대화에서는 닫힘 상태를 유지한다. 전송 실패 시 입력을 유지하고 재시도를 허용하며 노출 제한은 저장하지 않는다.

기존 `POST /api/feedbacks`를 재사용한다. 서버에는 피드백 종류 필드가 없으므로 AI 평가는 content에 고정 접두어 `[AI 대화 피드백]`를 붙여 서비스 의견과 구분한다. 선택 의견은 기존대로 최대 200자이며, 접두어를 포함해 서버의 255자 제한 이내다. 대화 원문·질문·답변은 전송하지 않는다. `feedback_submit` 분석 이벤트의 고정 source는 메뉴의 경우 기존 `service_layout`, 대화의 경우 `ai_chat`이며 만족도와 의견 원문은 분석 이벤트에 넣지 않는다.

평가 버튼과 전송 버튼은 공용 Button을 사용한다. 평가 미선택은 disabled, 전송 중 실행 차단은 loading으로 구분해 전송 버튼의 이름과 초점을 유지한다. 메뉴 폼의 필드는 FeedbackFormFields로 공유하며, 모달 내용과 표시 방식은 퇴장 완료까지 유지한다. AI 피드백의 노출 횟수 판단은 aiChatFeedback 모델, 재노출 제한·저장소·전송 상태는 useAiChatFeedback 훅이 담당한다.
