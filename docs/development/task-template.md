# 개발 시작 시 요구사항

기존 Task에 적힌 내용은 링크로 대체한다. 작은 변경에서는 필요한 항목만 작성한다.
요구사항은 사람이 확인하며 AI가 제안한 정책은 확정 전까지 미결정으로 남긴다.

- Task ID / URL:
- 목적: 사용자의 어떤 문제를 해결하는가?
- 동작: 어떤 조건에서 어떤 결과가 나와야 하는가?
- 예외: 권한 없음·대상 없음·변경 불가 상황을 어떻게 처리하는가?
- 완료 조건: 무엇을 검증하면 완료인가?
- 범위 밖: 이번 작업에서 다루지 않는 인접 기능은 무엇인가?
- 미결정: 구현 전에 확인해야 하는 정책은 무엇인가?
